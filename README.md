# Betnero, tema a blocchi

Tema WordPress a blocchi per betnero.it (senza Elementor).

- Aggiornamenti automatici con il plugin Git Updater (repository `d4rkcloud75/betnero-theme`, branch `main`).
- Per pubblicare una nuova versione: aumentare `Version` in `style.css` e `BETNERO_THEME_VERSION` in `functions.php`, poi commit e push su `main`.
